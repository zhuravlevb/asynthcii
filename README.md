# asynthcii

_ascii + synth_

Веб-синтезатор, вдохновленный 8-bit эстетикой ранних компьютеров. Звук характерный для той эпохи — грязные sawtooth, lo-fi звучание, шипение пленки.

## Особенности

- Весь интерфейс рисуется символами (даже крутилки!)
- Фон страницы выполняет роль визуалайзера и меняет свой тон в зависимости от громкости
- Возможность добавлять несколько синтов, которые будут играть параллельно

## Сочетания клавиш

- Пробел — play/pause
- Стрелки влево/вправо — переключение между синтами
- Cmd + перетягивание мыши — нота каждые 8 точек

## ИИ

Для создания синтезатора использовалась модель Anthropic Claude Opus 5.5.
